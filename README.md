## 📡 [真价雷达 PriceRadar](https://github.com/SSNN666/PriceRadar) —— 跨平台到手价决策 Agent

同一件商品，拼多多券后价和京东百亿补贴哪个真便宜？问 LLM 它会直接给你一个数——但它算的钱不能信。
这个项目的边界是**「钱不由 LLM 算」**：LLM 只负责理解意图、自主决定调哪些工具（自研工具调用循环），
到手价、同款判定、时机判断全部是确定性代码；数据全走拼多多 / 京东**官方联盟 API**，不碰爬虫。

| | |
|---|---|
| **同款判定** | 218 对自建评测集规则方案全通过；向量方案实测 70.2%，**被自己否决**——负结果报告 + 护栏测试钉住判定路径 |
| **Agent 行为** | 8 场景真实模型响应录制回放：工具选择 8/8、降级率 0%、硬失败后无徒劳重试；prompt 缓存命中 **79–87%** |
| **成本** | 单次查询 **￥0.0016**（纯比价）～ **￥0.20**（含一次风险扫描），工具内部的检索与 LLM 调用一并计入 |
| **接口** | SSE 流式（首帧 **1.2s** 到达）+ **MCP Server**（stdio），开放比价 / 风险扫描 / 价格观测三工具给 Claude · Cursor |
| **工程** | **570 项** pytest（conftest 全局禁网）+ GitHub Actions CI |

> 口径诚实：跨平台同款可比命中率约 **11%**（18 个查询实测）——京东定位为「偶尔捡漏」的增值项，不承诺全平台比价；页面展示公开优惠测算价，以结算页为准。

## 🏋️ [AI 健身教练](https://github.com/SSNN666/fitness-rag-coach) —— 安全约束 RAG 问答系统

健身与运动康复场景里，答错一句就是运动损伤。所以这个项目的目标不是「答得上」，
而是**「不该答的绝不答」**：三路召回 + 生成前边界拒绝 + 独立小模型事实核查，覆盖 28 类伤病的明确禁忌动作。

| | |
|---|---|
| **检索** | 100 条标注测试集 Hit@1/3/5 = **0.79 / 0.90 / 0.95**，MRR **0.85** |
| **性能** | 简单问答端到端 **42s → 3.2s**；并发 1→32 吞吐 **110 → 1682 token/s** |
| **故障韧性** | 图谱停机时单次调用 **34.53s → 4.08s**，熔断打开后 **0.0000s** |
| **工程** | **307 项** pytest + GitHub Actions CI；Docker 镜像 2.97GB → 1.38GB |

🔗 **[在线演示](https://ssnn666.github.io/fitness-rag-coach/)** —— 点开即看，不用 clone、不用配环境、不用 Key。

## 🛒 [电商用户画像与智能分析平台](https://github.com/SSNN666/user-insight-bot) —— LangGraph Agent

运营想知道「哪些高价值用户要流失了」，但要么不会写 SQL，要么得等数据团队排期。
这个项目让他**直接用自然语言提问**，系统自主调工具取数、自己核对每个数字，
并在**没人提问的时候主动报警**。

- **两条 Agent 路径**：交互问答走 **6 节点 StateGraph**（意图识别 → LLM 决策 → 工具执行 → 数据自检 → 回答生成 → 事实核查）；
  自主监控触发 **3 角色多智能体编排**（Monitor → Analysis → Strategy）
- **反幻觉**：自建对抗基准（43 条注入错误 + 34 条干净改写）→ **拦截率 100% / 误报率 0%**，
  单次核查 **0.09ms**（纯函数，**零 LLM 调用、零额外 Token**）
- **337 项** pytest + CI；FastAPI（4 中间件 + 48 路由）+ Vue 3 + Docker Compose

**技术栈**：Python · FastAPI · SSE · LangGraph · MCP · Milvus · Neo4j · BM25 · SQLite · Docker · pytest
